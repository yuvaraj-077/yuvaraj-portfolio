# Yuvaraj — Personal Portfolio

A responsive, frontend-only portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Download and extract `yuvaraj-portfolio.zip`.
2. Open the `yuvaraj-portfolio` folder.
3. Double-click `index.html` to open it in your browser.
4. Recommended: use VS Code with the **Live Server** extension, then right-click `index.html` and select **Open with Live Server**.

No npm, backend, or database is required.

## Personalize before publishing
- Update the About section in `index.html` with your own introduction.
- Replace the three project placeholders with real projects. Update each title, description, technology tags, and repository URL. Do not leave placeholder cards in a final job application portfolio.
- Change the skills only to skills you can confidently discuss. Skill bars are illustrative visual decoration, not verified proficiency ratings.
- The email link currently uses the email address supplied for this portfolio. Update it if needed.
- Add your real resume link only when you have a resume file ready.
- Google Fonts loads from the internet; the site still works without it, using fallback fonts.

## Publish free with GitHub Pages
1. Create a GitHub repository, for example `yuvaraj-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the published URL shown in the Pages settings.

## Files
- `index.html` — page content and sections
- `style.css` — layout, gradients, responsive styles, and animations
- `script.js` — mobile menu, scroll reveals, current year, and hero typing effect
